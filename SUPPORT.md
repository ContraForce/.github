# Support

GitHub is not a support channel for ContraForce. Use the routes below so your request
reaches a person who can act on it.

## Customers and partners

| I need to... | Go to |
| - | - |
| Open a support request | [help.contraforce.com](https://help.contraforce.com/helpcenter/support/contact-us) |
| Track an existing request | [My requests](https://help.contraforce.com/helpcenter/support/user/requests) |
| Read product documentation | [docs.contraforce.com](https://docs.contraforce.com) |
| Look something up in the API reference | [API reference](https://docs.contraforce.com/api-reference/introduction) |
| Onboard a workspace | [Workspaces guide](https://docs.contraforce.com/onboarding-customer-workspaces) |
| Email support directly | [support@contraforce.com](mailto:support@contraforce.com) |

## Sales and evaluation

- Start a trial or talk to us — [contraforce.com/signup](https://www.contraforce.com/signup)
- Sales — [sales@contraforce.com](mailto:sales@contraforce.com)
- General enquiries — [contact@contraforce.com](mailto:contact@contraforce.com)

## Security

Do not report vulnerabilities through support or a public issue. Follow
[SECURITY.md](SECURITY.md).

## ContraForce engineers

Work is tracked in Jira at [contraops.atlassian.net](https://contraops.atlassian.net),
not in GitHub issues. See [CONTRIBUTING.md](CONTRIBUTING.md) for the workflow.
